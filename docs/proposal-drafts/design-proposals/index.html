Halaman Pengguna

Untuk peranan Awam, Guru, dan Juri.

5 mockup
01 — Landing Portal Awam

Hero banner, fasa pertandingan, jadual episod, statistik.
02 — Pendaftaran

Wizard 5-langkah: sekolah → pasukan → peserta → bahan → semakan.
03 — Dashboard Guru

Senarai pasukan, status submission, profil sekolah.
04 — Penjurian (Juri)

Video player, slaid carousel, borang pemarkahan rubrik.
05 — Chatbot WhatsApp

Perbualan AI chatbot dengan Guru tentang pendaftaran, hadiah, eskalasi helpdesk.

Halaman Pentadbir (CMS)

Untuk Admin dan SuperAdmin RTM.

4 mockup
01 — Dashboard Admin

Stats cards, carta trend, recent activity, episod akan datang.
02 — Pengurusan Penyertaan

Filter, bulk action, table dengan status, eksport Excel.
03 — Editor Kandungan

CMS halaman, pengumuman, media library dengan WYSIWYG.
04 — Analitik

3-tier dashboard, carta, peta Malaysia, eksport laporan.

Nota Mockup

  • Mockup dibina dengan Bootstrap 5.3 + Bootstrap Icons + Google Fonts (Poppins/Inter) via CDN.
  • Setiap halaman self-contained — boleh dibuka direct dalam browser.
  • Mobile-responsive automatik (Bootstrap grid).
  • Sample data dalam Bahasa Melayu dengan nama sekolah dan peserta yang realistik.
  • Tema warna RTM Biru Klasik + aksen kuning/oren untuk audien pelajar.
  • Untuk eksport PNG/PDF, gunakan browser screenshot atau Chrome DevTools (Cmd+Shift+P → "Capture full size screenshot").
